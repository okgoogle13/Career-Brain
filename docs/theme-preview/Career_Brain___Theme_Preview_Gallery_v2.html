Previews use the viewer's installed fonts and may differ slightly from Google Docs. Each page names the exact approved font first, then a metric-similar fallback (for example Calibri → Carlito). No webfonts are loaded.

Heading font = first entry of heading_font_family, applied to the name, headline, section headings, role titles and KSC criterion text (the same roles as tools/build_golden_master.py). Where that field is absent, headings render in the body font and the card says "not specified".
